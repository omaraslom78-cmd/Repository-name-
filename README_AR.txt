مشروع روليت الخضار — Android

المحتويات:
- تطبيق Android يفتح لعبة محلية داخل WebView.
- وضع عشوائي موزون حسب الأوزان التي تضبطها.
- وضع يدوي لاختيار نتيجة محددة.
- تعديل أسماء العناصر والرموز والمضاعفات والأوزان، وإضافة/حذف عناصر.
- سجل آخر النتائج وتشغيل تلقائي بفاصل زمني.
- لوحة تحكم مقفلة برمز مالك محلي.

رمز المالك الأولي: 2468
غيّره من داخل التطبيق بعد فتح لوحة التحكم.

بناء APK:
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد (يجب أن يكون مجلد .github موجوداً).
2. افتح Actions في GitHub.
3. اختر Build Vegetable Roulette APK ثم Run workflow.
4. بعد نجاح البناء، افتح نتيجة التشغيل وحمّل Artifact باسم Vegetable-Roulette-APK.
5. فك ضغط الملف لتحصل على app-debug.apk.

ملاحظة:
هذه لعبة مستقلة ومحلية للتجربة والترفيه. لا تتصل ببيجو لايف ولا تتحكم بنتائجها أو خوادمها.
رمز المالك حماية محلية بسيطة وليست نظام حسابات أو حماية عالية الأمان.
